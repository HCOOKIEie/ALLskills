来自真实的开源仓库

使用 GitHub Search API 发现候选仓库，以名称、描述和 Topics 自动分类。收录对象是仓库，一个仓库可能包含多个技能，也可能是框架或 MCP 工具。

分类可能有误判。搜索支持多个关键词、引号短语，以及 owner:、topic:、lang:，前缀 - 可以排除关键词。

核验意味着什么？

「已发现 SKILL.md」表示 GitHub 文件树或 jsDelivr 镜像索引中存在同名文件。它是文件存在性核验，不代表质量审查或安全背书。

快照与手动同步

完整数据在采集时生成；「同步 GitHub」按当前目标读取最多 20 个最近更新的仓库并合并到本次浏览。同步结果不写回仓库，也不会把未核验的结果标为已核验。

GitHub API 有匿名配额。离线或额度不足时，你仍然可以搜索快照、收藏和浏览已有数据。

一个安静的私人工具箱

收藏和目标偏好保存在当前浏览器，没有账户也能使用。清除浏览器数据会移除收藏，切换设备不会自动同步。

分享筛选和单个仓库链接可以帮助你把发现带给别人。本地 file:// 链接需要对方也有同一份项目文件。
